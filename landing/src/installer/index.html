Installation · Linux

Installer Huggor en une commande

Ouvrez un terminal, collez la commande ci-dessous et validez. Huggor s'installe dans votre dossier personnel, sans sudo, après vérification de l'intégrité du paquet.

Commande d'installation

{{INSTALL_COMMAND}}

Version publiée : {{RELEASE_VERSION}} {{RELEASE_DATE}} · paquet {{DEB_NAME}} ({{DEB_SIZE}}), indépendant de l'architecture.

Pas à pas

Après l'installation

  1. Lancer Huggor

    Dans le terminal :

    huggor

    Si la commande est introuvable, ajoutez ~/.local/bin à votre PATH. Au premier lancement, les dépendances Python s'installent dans un environnement isolé (connexion Internet nécessaire) : gardez le terminal ouvert.

  2. Ouvrir l'interface

    Dans votre navigateur : http://127.0.0.1:7860. Arrêt de l'application avec Ctrl+C dans le terminal.

  3. Indiquer votre RAM et votre VRAM

    Dans l'onglet Hardware, déclarez la mémoire de votre machine pour estimer quelles précisions d'un modèle y tiennent. Un token Hugging Face (export HF_TOKEN=… avant huggor) est facultatif : il ne sert que pour les dépôts privés ou protégés.

Avant de commencer

Prérequis

  • Linux (testé sous Debian ; le script n'utilise pas apt)
  • python3 en version 3.10 ou supérieure, avec son module venv (Debian/Ubuntu : sudo apt install python3-venv)
  • curl, tar, sha256sum, flock, et dpkg-deb ou ar
  • Une connexion Internet à l'installation et au premier lancement

Il n'existe pas de binaire Windows ni macOS. Sur ces systèmes, Huggor se lance depuis les sources : voir les instructions du dépôt (nouvel onglet).

Ce que fait la commande

  1. Détermine la dernière release publiée sur huggor-downloads (nouvel onglet).
  2. Télécharge le paquet en HTTPS et vérifie son SHA-256 : en cas d'écart, rien n'est installé.
  3. Place le code dans ~/.local/lib/huggor et crée la commande ~/.local/bin/huggor.
  4. Ajoute une entrée « HF Explorer » au menu des applications.

Vos favoris et le cache sont conservés dans ~/.local/share/hf-explorer/ lors des mises à jour et de la désinstallation.

Gérer l'installation

Lire, mettre à jour, désinstaller

Lire le script avant de l'exécuter

curl -fsSL {{INSTALL_URL}} -o install-huggor.sh
less install-huggor.sh
bash install-huggor.sh

Mettre à jour

Relancez la commande d'installation : le code est remplacé par la dernière release, vos données sont conservées. Pour une version précise, ajoutez -s -- --release X.Y.Z après bash.

Désinstaller

{{INSTALL_COMMAND}} -s -- --uninstall

Les favoris, le cache et l'environnement Python restent dans ~/.local/share/hf-explorer/ : supprimez ce dossier vous-même pour les effacer.

Installation manuelle (paquet Debian/Ubuntu)

Vous préférez télécharger le paquet vous-même ? Il est publié avec sa somme de contrôle.

Paquet .deb Somme SHA-256 Toutes les versions sur GitHub (nouvel onglet) 
sha256sum -c {{DEB_NAME}}.sha256
sudo apt install ./{{DEB_NAME}}

Avec ce paquet, la commande de lancement est hf-explorer (et non huggor).

Pas envie d'installer ?

L'application web s'ouvre directement dans votre navigateur, sans installation ni compte.
