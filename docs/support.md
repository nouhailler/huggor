# Support

## Comment signaler un problème

Ouvrir une [issue GitHub](https://github.com/nouhailler/huggor/issues) sur le dépôt `nouhailler/huggor`.

## Informations à fournir

- Version de l'application (visible dans l'écran « ℹ️ À propos », ou commit Git exact : `git rev-parse HEAD`)
- Mode d'accès : local (`python app.py`), paquet Debian, Hugging Face Space, ou Render
- Appareil et système d'exploitation
- Navigateur et sa version
- Message d'erreur exact affiché par l'application
- État de la connexion réseau au moment du problème
- Étapes précises permettant de reproduire le problème

Voir aussi le [Dépannage](troubleshooting.md) et la [FAQ](faq.md) avant d'ouvrir une issue : le problème y est peut-être déjà couvert.

## Releases

Le paquet Debian/Ubuntu est distribué via les [releases GitHub](https://github.com/nouhailler/huggor/releases).
